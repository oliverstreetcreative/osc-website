# lib/scripts/ — the Scripts module's shared logic 🤖

Created 10/3/26 by the client-website worker for SCRIPTS (the client's front door for scripting; design:
`Matters/client-website/SPEC.md` §14 v4).

**What the machine was thinking:** the editor (browser), the server render (hub, prompter, PDF) and every export must
agree on what a script says and how long it runs, so the logic they share lives here once, with no server-only or
browser-only imports.

- `timing.ts`: words ÷ pace (§14 Timing). THE implementation; nothing else re-implements timing.
- `timing.vectors.json`: test vectors, GENERATED by `python3 scripts/test_script_timing.py --vectors` from the
  reference `scripts/script_timing.py` (hand-checked lines + the real Harmon and Gex scripts). Don't hand-edit.
- `timing.test.mjs`: `node --test lib/scripts/timing.test.mjs` proves `timing.ts` matches the vectors.

Rules: erasable TypeScript only (Node runs the tests by stripping types), no regex lookbehind (older iPhones),
no imports from `@/` aliases in files the tests load. Live status: the matter's `HANDOFF.md`.
